# 持仓分析模块使用指南

## 1. 功能概述

持仓分析模块通过接入同花顺交易软件，实现以下功能：

- **持仓数据获取**：自动读取持仓股票、成本价、持仓数量等
- **盈亏分析**：计算每只股票的盈亏金额和比例
- **技术面分析**：复用选股系统的技术指标计算逻辑
- **风险监控**：检查止损止盈、均线破位等风险
- **操作建议**：生成买入/持有/减仓/卖出建议

## 2. 环境准备

### 2.1 安装依赖

```bash
cd astock_selector
pip install -r requirements.txt
```

### 2.2 安装同花顺客户端

下载地址：http://www.10jqka.com.cn/

安装完成后，记录安装路径，例如：
```
C:\同花顺证券行情交易委托合一独立下单版本\
```

### 2.3 配置环境变量

复制 `.env.example` 为 `.env`，编辑以下配置：

```bash
# 交易配置
TRADING_BROKER=ths                    # 券商：ths(同花顺), ht(华泰), yhzq(银河), gtja(国泰君安)
THS_EXE_PATH=C:/同花顺安装路径/trade.exe
TRADING_USER=你的用户名
TRADING_ACCOUNT=你的资金账号
TRADING_PASSWORD=你的通讯密码

# 止损止盈配置（可选）
STOP_LOSS_RATIO=0.08                  # 止损比例 8%
STOP_PROFIT_RATIO=0.20                # 止盈比例 20%
```

## 3. 使用方法

### 3.1 基础命令

#### 查看持仓分析
```bash
python main.py --position
```

#### 查看持仓 + 操作建议
```bash
python main.py --position --suggestion
```

#### 查看持仓 + 风险警示
```bash
python main.py --position --risk
```

#### 查看持仓 + 操作建议 + 风险警示
```bash
python main.py --position --suggestion --risk
```

#### 自动登录模式
```bash
python main.py --position --auto-login
```

## 4. 分析逻辑

### 4.1 技术面分析

复用选股系统的 `factors/technicals.py` 模块，计算以下指标：

| 指标 | 说明 |
|------|------|
| 均线系统 | MA5/10/20/60，判断多头/空头/震荡 |
| MACD | 金叉/死叉，零轴位置 |
| KDJ | 超买 (>80)/超卖 (<20)/中性 |
| RSI | 强势/弱势 |
| 综合得分 | 0-100 分 |

### 4.2 操作建议规则

| 情况 | 建议 | 条件 |
|------|------|------|
| **止损卖出** | 清仓 | 亏损≥8% 或跌破 MA60 |
| **止盈减仓** | 减仓 50% | 盈利≥20% 或盈利≥30% |
| **破位减仓** | 减仓 50% | 跌破 MA20 |
| **技术弱势** | 减仓 | 技术得分<40 |
| **强势加仓** | 买入 | 技术得分≥70 + 盈利 + 多头趋势 |
| **持有** | 继续持有 | 其他情况 |

### 4.3 风险监控规则

| 风险类型 | 触发条件 | 等级 |
|----------|----------|------|
| 止损触发 | 亏损≥8% | 🔴 危险 |
| 跌破 MA60 | 股价<MA60 | 🔴 危险 |
| 止损预警 | 亏损>5% | ⚠️ 预警 |
| 跌破 MA20 | 股价<MA20 | ⚠️ 预警 |
| 止盈触发 | 盈利≥20% | 🟡 观察 |
| 技术面弱 | 得分<40 | ⚠️ 预警 |

## 5. 注意事项

### 5.1 同花顺兼容性

- 支持同花顺独立委托版本
- 需要保持同花顺客户端运行
- 某些券商可能需要手动确认登录

### 5.2 安全提示

- 账号密码仅存储在本地 `.env` 文件
- 建议使用独立的通讯密码
- 不要将 `.env` 文件上传到代码仓库

### 5.3 技术限制

- easytrader 依赖 Windows 系统
- 需要图形界面（不支持纯命令行服务器）
- 某些券商版本可能需要调整配置

## 6. 常见问题

### Q: 连接失败怎么办？
A: 1. 确保同花顺客户端已启动并登录
   2. 检查 `THS_EXE_PATH` 路径是否正确
   3. 尝试使用 `--auto-login` 参数

### Q: 持仓数据为空？
A: 1. 确认账户有持仓
   2. 确认同花顺已正确登录
   3. 检查是否有未成交的委托

### Q: 如何修改止损止盈阈值？
A: 编辑 `.env` 文件中的 `STOP_LOSS_RATIO` 和 `STOP_PROFIT_RATIO`

### Q: 支持其他券商吗？
A: 目前支持：
- 同花顺 (ths)
- 华泰证券 (ht)
- 银河证券 (yhzq)
- 国泰君安 (gtja)

修改 `TRADING_BROKER` 配置即可切换。

## 7. 与选股系统集成

持仓分析模块可以与选股系统配合使用：

1. **对比分析**：将持仓股与选股结果对比，检查是否持有推荐股
2. **调仓建议**：根据选股结果，建议卖出弱势股、买入强势股
3. **业绩追踪**：记录选股准确率，优化策略
