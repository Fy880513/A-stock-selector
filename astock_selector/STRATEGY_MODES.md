# A 股选股系统 - 策略模式使用指南

## 1. 策略模式概述

系统支持多种策略模式，用户可以根据自己的投资风格选择和组合不同的策略。

### 策略类型

| 策略 | 说明 | 适用场景 |
|------|------|----------|
| **comprehensive** | 综合评分（原有系统） | 中线选股，稳健型 |
| **dragon** | 龙头战法 | 短线追热点，激进型 |
| **limit_up** | 涨停板分析 | 打板策略，超短线 |
| **ml** | ML 选股模型 | 量化选股，数据驱动 |
| **seat** | 龙虎榜席位 | 跟随主力，短线 |

---

## 2. 预设策略模式

### 2.1 稳健型 (conservative)

**策略配置：**
- 综合评分：100%

**特点：**
- 仅使用原有综合评分系统
- 基本面 + 技术面 + 资金面 + 热点面
- 适合中线投资（2-4 周）
- 风险相对较低

**使用方法：**
```bash
python main.py --strategy conservative --top-n 10
```

### 2.2 激进型 (aggressive)

**策略配置：**
- 龙头战法：60%
- 涨停板：40%

**特点：**
- 专注于龙头股和涨停股
- 适合短线追热点
- 风险较高，收益潜力大

**使用方法：**
```bash
python main.py --strategy aggressive --top-n 10
```

### 2.3 平衡型 (balanced)

**策略配置：**
- 综合评分：50%
- 龙头战法：30%
- ML 选股：20%

**特点：**
- 平衡中线和短线
- 结合传统评分和机器学习
- 适合大多数投资者

**使用方法：**
```bash
python main.py --strategy balanced --top-n 10
```

### 2.4 全策略融合 (all_in)

**策略配置：**
- 综合评分：40%
- 龙头战法：25%
- 涨停板：15%
- ML 选股：10%
- 龙虎榜席位：10%

**特点：**
- 使用所有可用策略
- 多维度评估股票
- 最全面的选股方式

**使用方法：**
```bash
python main.py --strategy all_in --top-n 10
```

## 6. ML 选股模型

### 启用 ML 评分

```bash
# 综合选股 + ML 评分
python main.py --ml-score --date 2026-03-09 --top-n 10
```

### ML 特征说明

**技术指标：**
- MA 排列（5/10/20/60 日均线）
- MACD（DIF/DEA/HIST）
- KDJ（K/D/J）
- RSI
- 布林带

**动量特征：**
- 5 日/10 日/20 日收益率
- 波动率

**基本面：**
- PE TTM
- PB
- ROE
- 营收增长率
- 利润增长率

**资金流向：**
- 主力净流入
- 北向持股变化
- 大单占比

## 7. 策略切换建议

### 根据市场状态选择策略

| 市场状态 | 推荐策略 | 说明 |
|----------|----------|------|
| 牛市 | aggressive / all_in | 激进策略，充分参与 |
| 震荡市 | balanced | 平衡策略，稳健为主 |
| 熊市 | conservative | 保守策略，控制风险 |
| 热点轮动快 | dragon | 龙头战法，追热点 |
| 量化行情 | ml | ML 选股，数据驱动 |

### 根据投资风格选择

| 投资风格 | 推荐策略 | 持股周期 |
|----------|----------|----------|
| 稳健型 | conservative | 2-4 周 |
| 平衡型 | balanced | 1-2 周 |
| 激进型 | aggressive / dragon | 3-5 天 |
| 超短线 | limit_up | 1-2 天 |

## 8. 自定义策略权重

可以通过修改 `selector/strategy_manager.py` 中的 `default_weights` 自定义策略权重：

```python
# 示例：自定义权重
manager.strategies = {
    "comprehensive": StrategyConfig(
        mode=StrategyMode.COMPREHENSIVE,
        weight=0.6,  # 60%
        enabled=True,
    ),
    "dragon": StrategyConfig(
        mode=StrategyMode.DRAGON,
        weight=0.4,  # 40%
        enabled=True,
    ),
}
```

## 10. 风险提示

⚠️ **重要提示：**

1. **策略风险不同**：激进型策略风险高于稳健型
2. **历史表现不代表未来**：回测成绩不代表实际收益
3. **ML 模型限制**：ML 评分基于历史数据，存在滞后性
4. **龙虎榜数据延迟**：龙虎榜为盘后数据，次日可能已经变化
5. **止损设置**：使用任何策略都应设置止损
